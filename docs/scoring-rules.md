# 異常行為統計

目前目標為逐玩家、逐規則統計，取代信用分數。功能尚未發布，不提供舊評分格式相容或遷移。規則集為 `12-match-audit`，結果 schema 為 2；新歷史存於 `behavior-analysis`。

分頁名稱為「異常數據」。使用者在 demo detail 手動執行「異常分析」，一次準備整場共用資料並分析所有玩家。基本 demo 自動分析維持不變。進度只顯示一行：準備資料 → 分析玩家 → 彙整結果。

主表以玩家為列、整場有觀察次數的行為為欄；不顯示整場皆未出現的欄位，無個人次數的儲存格以「—」保持對齊。分析細節以 dialog 開啟，只顯示最新結果，不放分析歷史選單、頂部判斷說明或來源警告。底層批次結果仍保存供重用。

## 結果定義

- 每項規則獨立列出次數、有效樣本、量測摘要及原始回合／tick／目標。次數不合成總分、扣分或總異常排名。
- 同一規則、同回合、同目標的重疊區間合為一次；保留所有來源 ID 與量測值。不同規則各自計數，不互相抵銷，也不加權。
- 「0」代表存在有效樣本且沒有符合條件的事件；資料不足或分析失敗顯示「—」。比例必須有明確分母，沒有樣本不顯示 0% 或 100%。
- 條件是實驗性行為篩選，不是作弊判定。正常玩家也可能符合；由使用者檢視次數、比例、時序和上下文。

## 已接入的獨立規則

| ID | 計次單位及條件 |
| --- | --- |
| aim-snap | 實測瞬間對準後，連續停留同一敵方身體點至少 150 ms；短暫掠過不計次 |
| aim-linear-acquisition | 至少三個視角點符合快速直線對準條件，且之後連續對準敵方身體點至少 150 ms；短暫掠過、停在身體外或中途離開不計次。不要求射擊或可見，隔牆、煙霧內、受閃亦納入。150 ms 是暫定停留門檻，不是反應時間門檻 |
| aim-fixed-tracking | 持續跟隨同一身體點的區間；須有目標移動及量測 |
| view-angle-oscillation | 符合視角震盪條件的連續區間 |
| kill-penetration | 敵方槍械擊殺事件記錄穿透表面，每次擊殺一次 |
| kill-smoke | 敵方槍械擊殺事件標記穿煙，每次擊殺一次 |
| kill-blind | 敵方槍械擊殺事件標記攻擊者受閃，每次擊殺一次 |
| shot-synchronous-view-turn | 開槍同一 tick 球面視角改變至少 30°，下一 tick 再轉至少 30° 且回到原視角 3° 內；沒有連續回轉證據不計次。另列全體有效射擊平均角速度與比例 |
| shot-hit-rate | 同武器至少 10 發且命中率至少 85%，統計其中命中的發數；摘要另列全場有效射擊／命中／命中率 |
| first-shot-hit-rate | 同回合、同武器射擊相隔超過 0.3 秒視為新段；同武器至少 10 個首發且首發命中率至少 85%，統計命中首發數 |
| unbroken-hit-sequence | 至少 10 發連續命中的最大序列，整段一次；可跨回合，列起迄回合及連續發數 |
| rapid-multikill | 同回合 1.5 秒內 2 殺，或 3 秒內至少 3 殺；依時序取不重疊的最大符合群組，每群一次 |
| flashed-hit-rate | 記錄的受閃時間窗內，每發敵方命中一次；包含空槍的受閃發數作分母，不把受閃事件當成全白畫面 |

槍械發射以 tick／玩家／武器去重；敵方傷害配對同 tick 或前一 tick 的同武器射擊。同發多次傷害只計一發命中。只採有效回合內的槍械事件；基本 demo 統計的既有回合結束後統計範圍不變。

移動規則同樣隨全場共用串流執行：

| ID | 計次單位及條件 |
| --- | --- |
| bhop-speed-retention | 至少 3 次連續跳躍，水平速度至少 200 HU/s、相鄰起跳保速至少 98%，間隔不超過 2 秒、落地觀測不超過 2 個 tick；一段一次，另列最長連跳數 |
| fixed-view-air-strafe | 空中連續至少 3 步速度方向交替改變 2–10°，視角每步變化不超過 0.05°、水平速度每步增加至少 0.5 HU/s；一段一次，另列步數及速度 |

移動必須有實際 flags、正確解碼的 LastJumpTick／fraction、網路 tick、速度與位置，且走路移動模式、非水中、非梯子；未知值不補零。跳躍時鐘、生命身分、回合或取樣不連續會切段。落地 tick 觀測不等於精確落地反應時間。

## 情境命中率：使用者定義

| 情境 | 分母 | 分子 |
| --- | --- | --- |
| 穿煙 | 整場實際穿煙的射擊發數（含空槍） | 其中命中敵人的發數 |
| 受閃 | 整場受閃當下的射擊發數（含空槍） | 其中命中敵人的發數 |
| 穿牆 | 整場實際穿透表面的射擊發數（含空槍） | 其中穿透後命中敵人的發數 |

同一發造成多筆傷害或命中多個敵人，分子仍只算一發；率為分子／分母，不是擊殺率或占所有普通射擊的比例。不能只因未造成傷害就認定該發未穿煙／穿牆。

受閃目前已提供完整記錄時間窗內的射擊分母。新增 `smoke-hit-rate`／`penetration-hit-rate` 保留伺服器子彈命中事件確認的穿煙／穿透命中發數（不要求擊殺）；空槍路徑未合格，因此只列已確認命中和未判定射擊發數，不輸出命中率。規則 ID 的 rate 表示這項指標的目標，現行 UI 明確標為命中次數。`unclassifiedShots` 不是情境分母。

## 資料資格與尚未能提供的量測

TTD 定義為「敵方任意身體部位（包括剛露出的手臂邊緣）首次在實際視野中可見，到首次對同一敵人造成傷害」；目前缺乏已驗證的可見起點，不能用擊殺間隔、出現在畫面方向或穿煙旗標替代。小於 120 ms 也不是獨立的作弊判定。

穿煙／穿牆擊殺旗標不能提供所有射擊的路徑，故目前不能聲稱有完整穿煙／穿牆命中率。受閃時間窗不等於完全看不見。準星／發射方向也不等於子彈實際落點，缺少落點資料時不輸出彈著聚集率。可靠遮蔽跟隨、動態預瞄及純透視判定仍需要合格的視線來源。

## 共用與效能

通用转换保留整場資料，不依某條規則候選區間篩選。事件在共用讀取時收集一次，射擊與移動統計隨同全場處理，玩家只作結果歸屬。分析階段依所有規則共用的有效回合範圍略過非交戰骨架重建，但仍更新每個封包的完整狀態並重設規則連續性；這不篩掉任何通用轉換資料。約 35 MB 為目前容量方向；10 MB 留待優化。準備與全部規則／全體玩家各 30 秒仍是目標，實測與未達標項目見 [效能紀錄](analysis-performance.md)。
